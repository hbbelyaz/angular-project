# Test

Projet généré avec Angular CLI 21.1.4. Les styles globaux et ceux des composants sont configurés en SCSS.

## Développement

Installez les dépendances avec `npm install`, puis lancez le serveur :

```bash
npm start
```

Ouvrez `http://localhost:4200/`. Le serveur recharge l’application lors des modifications.

## Composants

Générez un composant avec Angular CLI ; les fichiers de style créés utiliseront `.scss` :

```bash
npx ng generate component nom-du-composant
```

Les styles globaux se trouvent dans `src/styles.scss`.

## Build et tests

```bash
npm run build
npm test
```
